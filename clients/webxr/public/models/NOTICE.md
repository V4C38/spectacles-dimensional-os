# OpenYAM planning ghost

`openyam.glb` is a simplified per-link convex-hull rendering of the canonical YAM
visual meshes used by DimOS. Each mesh is expressed in its original link frame;
link nodes are animated using the runtime's configured model descriptor.

Source: https://github.com/i2rt-robotics/i2rt

kinematics, physical tool offsets, or controller configuration is supplied by this asset.
